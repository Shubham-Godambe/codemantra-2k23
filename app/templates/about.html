About CODEMANTRA 2K23

Problem Statement

"Application of Image Analytics For Tree Enumeration For Diversion of Forest Land"

This project addresses the Smart India Hackathon problem statement focused on developing solutions for tree enumeration and forest land analysis using aerial imagery.

Project Overview

CODEMANTRA 2K23 is an AI-assisted geospatial computer-vision prototype designed to detect, enumerate, and analyze trees from aerial imagery. The system uses classical computer vision techniques combined with GIS visualization to provide insights into forest composition and tree density.

Objectives

  • 🌳 Automated tree enumeration from aerial images
  • 📊 Vegetation segmentation and analysis
  • 🗺️ Geospatial visualization and GeoJSON export
  • 📈 Tree density calculation and forest-land metrics
  • ✓ Ground-truth validation framework

Key Features

  • ✅ Drag-and-drop image upload (JPG, PNG, JPEG, TIFF)
  • ✅ Configurable tree detection parameters
  • ✅ Real-time tree detection with OpenCV
  • ✅ Visual overlay of detected trees on original image
  • ✅ Tree density calculation (trees per hectare)
  • ✅ Interactive Leaflet map with approximate geographic coordinates
  • ✅ Export to CSV and GeoJSON formats
  • ✅ Ground-truth validation with accuracy metrics
  • ✅ Statistical analysis and visualization

⚠️ Important Limitations

  • Classical Computer Vision MVP: Uses OpenCV and HSV thresholding, not deep learning. Accuracy depends on image quality and vegetation type.
  • Demo Coordinates: Geographic coordinates are approximate when GPS/georeferencing metadata is unavailable. Use configurable reference location.
  • No Species Classification: The system detects vegetation but does not classify tree species. Would require multispectral analysis or trained models.
  • Prototype Validation: Simple count-based validation. Production systems require spatial matching, IoU metrics, and field validation.
  • Not for Official Decisions: This is an academic prototype. Not intended for official forest-land approval decisions without proper validation.
  • Single-Image Processing: Processes one image at a time. No time-series or multi-temporal analysis.

How to Use

  1. Upload Image: Navigate to Dashboard, upload an aerial forest image
  2. Configure Parameters: Adjust detection thresholds if needed
  3. Run Detection: Click "Run Detection" to analyze the image
  4. View Results: See detected trees with statistics
  5. Explore Map: View trees on interactive Leaflet map
  6. Download Data: Export results as CSV or GeoJSON
  7. Validate: Compare detection against ground truth if available

For Researchers & Developers

This project is designed as an academic prototype suitable for:

  • 🎓 Student portfolios and Master's applications
  • 📚 Computer vision and GIS education
  • 🔬 Research on vegetation detection algorithms
  • 🏗️ Baseline for production forest-monitoring systems

The code is intentionally simple and well-documented for learning purposes. Production deployments would require trained models, real georeferencing, comprehensive validation, and proper data provenance.
